# Sistema de Gestión de Solicitudes Académicas

## Descripción

Sistema web para registrar, administrar y consultar
solicitudes académicas realizadas por estudiantes.

## Tecnologías

- PHP 8.2
- MongoDB Atlas
- MongoDB PHP Library
- Composer
- Bootstrap 5
- JavaScript
- Git y GitHub

## Instalación

1. Clonar el repositorio.
2. Instalar dependencias con Composer.
3. Configurar config/database.local.php.
4. Iniciar Apache desde XAMPP.
5. Acceder a la carpeta public desde el navegador.
